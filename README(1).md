# assets/ — Additional Resources

Place any extra website assets here, e.g.:

| File | Purpose |
|------|---------|
| `og-image.png` | Social share image (1200×630) for Open Graph |
| `posters/` | Radio show artwork / programme banners |
| `audio/` | Jingle, intro or recorded programme clips (optional) |
| `docs/` | Programme schedules, press kit, licensing documents |

The folder is referenced by the PWA service worker as non-critical content —
assets added here are cached automatically once visited.
